# ReLog

An early prototype for goals, trackers and everyday logging.

The interactive design prototype is in [sites/relog-motion](sites/relog-motion/README.md). It follows the supplied references in `design/my_design` and uses fictional, memory-only demo data.

Run from `sites/relog-motion`:

```sh
npm run dev
npm test
npm run test:browser
npm run build
```

Requires Node.js 22+, Python 3, and installed Chrome for browser checks. No dependencies or secrets are required. See [motion review](design/MOTION-REVIEW.md) for verified checks and limitations, and [prototype brief](design/PROTOTYPE.md) for the earlier Figma flow.
